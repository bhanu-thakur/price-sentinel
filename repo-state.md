# Repo state report

**The procedure is not here.** It lives in one place:

```
~/GitHub/ai-command-center/prompts/repo-state.md
```

To get a state report for this repo, open a session here and say:

> Read AGENTS.md, then give me the state report.

## Why this file is a pointer and not a copy

It *was* a copy, for about an hour on 2026-08-15, in six repos. Seven identical
files with nothing enforcing the match is the drift this whole setup exists to
prevent — the same argument that makes `CLAUDE.md` a pointer to `AGENTS.md`
rather than a second rulebook, and the same one behind
`volatile-numbers-are-generated` in the practice exchange.

**Do not paste the procedure back into this file.** If it is wrong, fix the
original; every repo picks the change up for free. If the original is
unreachable — a machine with no `ai-command-center` checkout — that is the thing
to fix, not this file.

The standing rules this repo follows during that report — pull practices before
comparable work, push what you prove, findings are the auditor's — are in this
repo's own `AGENTS.md`, because those bind every session here and not only a
state report.
